其余关键组件

§3.3–3.5 FFN · Embeddings · Positional Encoding

位置逐点前馈网络 论文

  • 两层线性变换 + ReLU,对每个位置独立且相同地作用
  • 输入/输出维度 d_model = 512,内层 d_ff = 2048;等价于两个 1×1 卷积

FFN(x) = max(0, xW1 + b1) W2 + b2

嵌入与权重共享 论文

  • 可学习嵌入把 token 映射为 512 维向量
  • 两个嵌入层与 softmax 前的线性层共享同一权重矩阵
  • 嵌入层权重乘以 √d_model

位置编码 论文

  • 无循环无卷积 → 必须注入顺序信息,与嵌入同维相加
  • 采用不同频率的正弦/余弦函数;选它的原因:相对位置可线性表示,且可能外推到更长序列
  • 与可学习位置嵌入效果几乎相同(Table 3 行 E)

PE(pos,2i) = sin(pos / 10000^(2i/d_model))
PE(pos,2i+1) = cos(pos / 10000^(2i/d_model))

解读 这三个组件各司其职:FFN 提供非线性变换容量,位置编码补上"顺序感",权重共享压缩参数量——注意力并不是孤军奋战。
