## 六、环境备忘（跑实验前先看，能省几小时）

1. **Key 现状与建议**：我扫了 110 个实验的 `env.example`，出现最多的密钥是
   `OPENAI_API_KEY`（47 个实验）> `OPENROUTER_API_KEY`（25）> `ARK/Kimi`（各 14）> `KIMI_API_KEY`（12）> `SILICONFLOW`（10）> 百炼 `DASHSCOPE`（9）> `GEMINI`（6）> `ANTHROPIC`（5）> `DEEPSEEK`（4）。
   **`OpenRouter` 的性价比最高**：多个实验（如 1-1 context、2-10 context-compression）在 `env.example` 里明确写了"未设置本家 key 时自动改走 OpenRouter"的回退逻辑。建议顺序：先用现有 DeepSeek key 跑 W0 → 按 W1/W2 需要再决定加 OpenRouter 或 Kimi/百炼。
2. **依赖安装走镜像**：本机 PyPI 直连会卡死，`uv sync` / `pip install` 一律加 `--index-url https://pypi.tuna.tsinghua.edu.cn/simple`；仓库 README 支持按章装 extra（`uv sync --locked --extra ch2`、`--extra vllm`、`--extra unsloth`）。
3. **别把仓库塞进 Obsidian 库**：1.6 GB，留在 `D:\hermes\ai-agent-book`，本目录只放笔记。
4. **大目录提醒**：`chapter2/prompt-engineering` 289 MB、`chapter3/user-memory` 111 MB、`chapter5/video-edit` 98 MB 自带素材，别再重复下载。
