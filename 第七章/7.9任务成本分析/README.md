## 先学一个公式

```text
成本 = [(总输入 - 缓存输入) × 普通输入单价
        + 缓存输入 × 缓存单价
        + 输出 × 输出单价] / 1,000,000
```

本例单价单位为美元/百万tokens，默认沿用固定样例的0.15、0.075、0.60。总输入已包含缓存命中部分，不能再把全部输入都按普通价收费。

例如总输入1000、其中缓存600、输出100：普通输入只有400，因此按本例假设重算为(400×0.15+600×0.075+100×0.60)/1,000,000 = 0.000165美元。这是计算示例，不是本机收费。

每组只有8个span，p95/p99采用官方nearest-rank规则，通常等于本组最大单步费用；不能据此估计生产尾部延迟或更大任务分布。源码的在线路径另有不加入正式tracers的预热，样例不证明覆盖了原运行所有预热/重试；工具服务、向量检索、基础设施、人工核对等成本也未包含在该模型token表中。
