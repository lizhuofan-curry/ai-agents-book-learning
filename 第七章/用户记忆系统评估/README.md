## 先分清分数与整题通过

四个维度是precision（事实精确）、recall（必要信息完整）、reasoning（关联/时序/消歧）、proactivity（适当的主动帮助）。每维1/2/3/4分别为fail/pass/good/excellent；单维的pass=2只表示部分满足。

原解析器将每维映射为(score−1)/3，再对四维取平均，得到0—1的reward。整题passed要求前三维都至少3，且没有幻觉否决；proactivity参与reward，但不单独成为任务成功的硬门槛。检测到幻觉时reward强制为0、passed为false。

| 预设数字示例 | 四维分数 | reward | 整题passed |
| --- | --- | ---: | --- |
| 核心维度满足要求 | 4、3、3、2 | 0.666667 | true |
| 召回只部分满足 | 4、2、3、2 | 0.583333 | false |
| 第一行分数但触发幻觉否决 | 4、3、3、2 | 0 | false |

这些分数由教学脚本预先指定，仅演示公式与门槛。证据数组留空，不假装已判读具体答案，不用于裁判校准或任务成功率统计。真实评分要另看原对话、真实答案及逐项证据；解析成功本身不能证明裁判判断正确。
