# 1.3搜索与代码执行

对应官方实验1-3，配套项目为`search-codegen`。

[官方详细步骤](https://github.com/bojieli/ai-agent-book/blob/main/chapter1/search-codegen/README.md)

理解模型怎样把搜索取得的信息交给代码工具处理，并在执行结果返回后继续决策。学习时进入上面的官方README，按其中的准备环境、配置服务和运行步骤操作。

本目录用于分类。开始此实验时在线查阅对应官方源码，按步骤编写学习代码；使用项目根目录的共享解释器。

自己的练习放`我的代码`，自己的输出放`运行结果`。
