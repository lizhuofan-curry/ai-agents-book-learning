## 第一次只看菜单分支

打开[10_引导式快速体验.py](我的代码/10_引导式快速体验.py)，先看main中的这些行：

```python
mode = input("请选择（1-3）：").strip()

```

input返回字符串，所以输入3后，mode是"3"。条件成立，return结束main。这发生在读取.env和创建Agent之前，因此不会调用API，也不会生成问答JSON。

在10文件上右键，选择运行。看到菜单后先输入3，观察结束分支。

## 模式编号怎样选择函数

```python
if mode == "1":
    demo_search(agent)
elif mode == "2":
    interactive_mode(agent)
```

demo_search与interactive_mode是本文件自己定义的Python函数；它们都接收同一个Agent对象。菜单由Python处理，模型只会收到最后选定的问题。

| 输入 | mode的值 | 后续动作 |
|---|---|---|
| 1 | "1" | 调用demo_search，显示问题列表 |
| 2 | "2" | 调用interactive_mode，等待完整问题 |
| 3 | "3" | return退出 |

## 演示问题的编号与列表索引

demo_search保留官方三个问题。下面这行同时取得显示编号与问题：

```python
for i, question in enumerate(demo_questions, 1):
    print(f"{i}. {question}")
```

enumerate是Python内置函数，第二个参数1让显示编号从1开始。列表本身的索引仍从0开始：

| 显示编号 | 列表索引 | 官方演示问题 |
|---|---|---|
| 1 | 0 | OpenAI最新发布了什么产品？ |
| 2 | 1 | 2024年有哪些重要的AI突破？ |
| 3 | 2 | 如何开始学习机器学习？ |

```python
choice = int(input("请选择（0-3）：").strip())
question = demo_questions[choice - 1]
```

这里int将选择的字符串转成整数。若输入2，choice为整数2，choice - 1为1，于是取列表第2个问题。代码先检查1<=choice<=len(demo_questions)，再取索引。

输入0则进入自定义问题分支，通过另一个input取得完整问题。非法编号或空问题不会调用搜索。

## 一次完整的数据流

准备真实体验时，可依次选择1、0，然后输入：

```text
请搜索Python3.11官方文档，用100字以内解释tomllib的用途，给出1个官方链接。完成一次搜索后，根据已有结果回答；如果证据不足，请明确说明。
```

对应变量变化为：

```text
模式输入"1" → mode="1" → 调用demo_search
问题编号输入"0" → choice=0 → 接收自定义问题
question=完整问题字符串 → run_question(agent, question)
→ agent.search_and_answer(question, max_iterations=5)
→ 打印回答并保存JSON
```

run_question是我们提取的共同问答与保存函数，内容沿用07至09。demo_search和interactive_mode都调用它，因此不用在两个地方重复写保存代码。

演示结束后，输入n结束本次快速体验；输入y则调用interactive_mode，继续独立提问。每题记录按北京时间单独保存到运行结果/引导式体验。真实执行需要继续检查状态、工具回传和来源；达到上限或工具失败时记录仍标为未完成。
