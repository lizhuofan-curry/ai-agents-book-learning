## 本步只看信息怎么提供

- 全量展示：126个工具完整定义。
- 按需模式初始示意：calculator、get_current_time和discover_tools，共3个定义。
- 人工候选：对“找Transformer论文并下载”固定展示arxiv_search和download_file。
- 人工追加后示意：3个初始定义加2个候选，共5个。

候选名称人工给定，没有检索算法、模型决策或任务评分；这不是主动发现能力提升。discover_tools也只是接口示意，没有在本步执行。后续需要观察模型是否会提出发现需求，以及系统能否返回真正所需工具，而不是把人工候选当成功结果。

程序以同一种紧凑JSON序列化测量字符数和UTF-8字节数，不把它们叫token。初始/追加后的体积是展示视图大小，不是多轮总成本：已有对话可能不断累积，还会新增发现调用及返回。官方其他模型、token数字、延迟和准确率不能直接搬作本机结果。

正式运行生成record.json、四份展示视图JSON及工具目录阅读.md。看到TOOL_CATALOG_READING_SAVED后发回输出，先解释说明量差异，再进入可执行发现流程。--preview只核对来源及目录，不创建正式结果。
