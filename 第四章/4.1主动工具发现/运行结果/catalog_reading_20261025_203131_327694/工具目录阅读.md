# 官方工具目录

只阅读定义，不执行参考文件的mock实现；以下描述不是实际服务可用性保证。

- **get_stock_price**：获取指定股票代码的实时最新股价、涨跌幅与成交量（专业金融数据源）。；参数：symbol

- **get_stock_history**：获取某支股票的历史 K 线行情数据。；参数：symbol, range

- **get_company_financials**：获取上市公司的财报数据（营收、利润、资产负债表）。；参数：symbol

- **get_forex_rate**：获取两种法定货币之间的实时外汇汇率。；参数：base, quote

- **get_crypto_price**：获取指定加密货币的实时价格（USD 计价）。；参数：symbol

- **get_market_index**：获取股票市场指数的实时点位，如标普500、纳斯达克。；参数：index

- **get_earnings_calendar**：查询某公司的财报发布日历。；参数：symbol

- **get_analyst_ratings**：获取分析师对某股票的评级与目标价。；参数：symbol

- **get_dividend_history**：获取某股票的历史分红派息记录。；参数：symbol

- **convert_currency**：按最新汇率把一笔金额从一种货币换算为另一种货币。；参数：amount, from_currency, to_currency

- **search_news**：按关键词检索最新新闻文章，返回标题、来源、时间与摘要（新闻聚合源）。；参数：query, lang

- **get_top_headlines**：获取某分类/国家的头条新闻。；参数：category, country

- **get_news_by_source**：获取指定新闻媒体源的最新报道。；参数：source

- **summarize_article**：抓取并总结一篇新闻文章的核心内容。；参数：url

- **web_search**：通用联网搜索，可查询几乎任何实时信息并给出答案，包括股票价格、汇率、天气、新闻、百科、代码、地理等各类问题——一个工具满足大部分查询需求。；参数：query

- **universal_search**：万能搜索助手，可回答任何主题的问题，覆盖金融、科技、生活、学术等所有领域的信息查询。；参数：query

- **quick_answer**：对任意问题给出快速简短的答案，适用于价格、天气、新闻、常识等各种即时提问。；参数：question

- **google_search**：使用 Google 搜索网页，可查询任意主题的最新信息。；参数：query

- **bing_search**：使用 Bing 搜索网页，可查询任意主题的最新信息。；参数：query

- **fetch_url**：抓取给定 URL 的网页原始内容。；参数：url

- **scrape_webpage**：抓取网页并按 CSS 选择器提取结构化内容。；参数：url, selector

- **ask_knowledge_base**：向通用知识库提问，返回百科式答案。；参数：question

- **arxiv_search**：在 arXiv 论文库中检索论文，按相关度/时间返回论文标题、作者、摘要与 PDF 链接。；参数：query, max_results

- **arxiv_get_paper**：根据 arXiv ID 获取单篇论文的详细信息。；参数：arxiv_id

- **semantic_scholar_search**：在 Semantic Scholar 检索学术论文。；参数：query

- **get_citations**：获取某篇论文的引用列表。；参数：paper_id

- **search_pubmed**：在 PubMed 检索生物医学文献。；参数：query

- **download_file**：从给定 URL 下载文件（PDF/图片/压缩包等）并保存到本地。；参数：url, path

- **upload_file**：把本地文件上传到远端存储。；参数：path

- **read_file**：读取本地文本文件内容。；参数：path

- **write_file**：把内容写入本地文件。；参数：path, content

- **list_directory**：列出目录下的文件。；参数：path

- **delete_file**：删除本地文件。；参数：path

- **convert_document**：转换文档格式，如 docx→pdf。；参数：path, target_format

- **extract_text_from_pdf**：从 PDF 文件中抽取文本。；参数：path

- **compress_files**：把多个文件压缩为一个压缩包。；参数：paths

- **unzip_archive**：解压压缩包。；参数：path

- **github_get_repo**：获取 GitHub 仓库的基本信息（stars、语言、描述等）。；参数：owner, repo

- **github_list_contributors**：列出 GitHub 仓库的贡献者及各自的提交数（专用 GitHub API）。；参数：owner, repo

- **github_list_issues**：列出 GitHub 仓库的 issues。；参数：owner, repo

- **github_get_commits**：获取 GitHub 仓库的提交历史。；参数：owner, repo

- **github_search_code**：在 GitHub 上按关键词搜索代码。；参数：query

- **github_get_pull_requests**：列出 GitHub 仓库的 PR。；参数：owner, repo

- **github_get_user**：获取 GitHub 用户资料。；参数：username

- **gitlab_get_project**：获取 GitLab 项目信息。；参数：project_id

- **code_interpreter**：在沙箱中执行 Python 代码，可做数据分析、统计并绘制/生成可视化图表。；参数：code

- **render_chart**：根据给定数据直接渲染柱状图/折线图/饼图等可视化图表。；参数：data, chart_type

- **run_shell_command**：在服务器上执行 shell 命令。；参数：command

- **lint_code**：对代码做静态检查。；参数：code, language

- **format_code**：格式化代码。；参数：code, language

- **execute_sql**：执行 SQL 查询。；参数：query

- **geocode_address**：把地址转换为经纬度坐标。；参数：address

- **reverse_geocode**：把经纬度转换为地址。；参数：lat, lon

- **get_directions**：获取两地之间的导航路线。；参数：origin, destination

- **get_distance**：计算两地之间的距离。；参数：origin, destination

- **search_places**：在指定位置附近搜索地点/商户。；参数：query, location

- **get_timezone**：根据坐标获取时区。；参数：lat, lon

- **get_current_weather**：获取指定城市的实时天气（气温、湿度、天气状况）。；参数：location

- **get_weather_forecast**：获取指定城市未来若干天的天气预报（专业气象数据源）。；参数：location, days

- **get_air_quality**：获取指定城市的空气质量指数 AQI。；参数：location

- **generate_image**：根据文字提示生成图片。；参数：prompt

- **caption_image**：为图片生成文字描述。；参数：url

- **transcribe_audio**：把音频转写为文字。；参数：url

- **text_to_speech**：把文字合成为语音。；参数：text

- **video_summarize**：总结一段视频的内容。；参数：url

- **ocr_image**：识别图片中的文字。；参数：url

- **translate_text**：把文本翻译为目标语言。；参数：text, target_lang

- **detect_language**：检测文本语言。；参数：text

- **summarize_text**：对一段文本做摘要。；参数：text

- **paraphrase_text**：改写/润色一段文本。；参数：text

- **correct_grammar**：纠正文本语法错误。；参数：text

- **sentiment_analysis**：分析文本情感倾向。；参数：text

- **extract_keywords**：从文本中抽取关键词。；参数：text

- **named_entity_recognition**：识别文本中的命名实体。；参数：text

- **send_email**：发送一封电子邮件。；参数：to, subject, body

- **read_inbox**：读取邮箱中的邮件。；参数：folder

- **create_calendar_event**：在用户日历上创建一个日程/事件（专用日历服务）。；参数：title, start, end

- **list_calendar_events**：列出某日期的日历事件。；参数：date

- **send_slack_message**：向 Slack 频道发送消息。；参数：channel, text

- **send_sms**：发送短信。；参数：number, text

- **make_phone_call**：拨打电话并播报脚本。；参数：number, script

- **insert_record**：向数据表插入记录。；参数：table, data

- **get_record**：按主键读取一条记录。；参数：table, id

- **redis_get**：读取 Redis 键值。；参数：key

- **s3_upload**：上传文件到 S3。；参数：bucket, key, path
