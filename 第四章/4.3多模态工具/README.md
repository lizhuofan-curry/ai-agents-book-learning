# 4-3：多模态工具

当前先生成并人工阅读同一张测试图，不进行模型比较。接下来学习原图直接输入、先提取文本再问答、按需工具分析三条路线，分别检查信息保留、提取误差与回答依据。

```bash
.venv/bin/python "第四章/4.3多模态工具/我的代码/01_生成并阅读测试图.py"
```

也可VS Code打开01点击运行。原项目环境已有matplotlib/Pillow，不安装新包、不用Ollama、API Key或网络，只生成PNG，不生成PDF或调用OCR。每次新建运行目录，不覆盖旧图片。

参考官方create_sample.py，只调用其create_chart，生成900×600的合成季度营收柱状图。横轴Q1至Q4，纵轴Revenue(in $M)，柱顶显示精确数值。问题为“哪个季度营收最高，具体数值是多少？请说明单位。”先人工查看图中信息，后看独立标准参考。

产物：sample_chart.png、图片阅读说明.md、标准参考_仅供核对.json及record.json。生成器内的数组与参考答案只作离线核对，后续模型请求必须排除，不能把它们当作OCR或图像提取结果。运行记录保存来源、图片和代码哈希及绘图版本，不能只凭固定数据一致假设不同渲染版本像素相同。

2026-10-25只读查询本机Ollama显示现有qwen3.5:9b具有vision能力，后续可考虑本机图片输入；本步骤没有生成请求。支持vision不等于本例必然识别正确，三路线也不能提前标记完成。
