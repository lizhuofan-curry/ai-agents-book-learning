## 这一步在做什么

3-4根据语义给出一份排名，3-5根据词项匹配给出另一份排名。本步将这两份已有排名合并，观察同一篇文档合并后排到哪里。

沿用同一12篇英文文档、5条查询和官方相关性标注，复用两份已核对实测记录。每路取最多前5篇，去重后形成候选并集；融合对整个并集排序，最后取前5评估。完整并集与排名另行保存，便于下一步重排使用。BM25额外编码查询没有稠密对照，本步不纳入。

| 方法 | 如何得到顺序 | 本步是否新调用模型 |
| --- | --- | --- |
| Dense | 读取3-4保存的余弦排序，截取前5 | 否 |
| Sparse | 读取3-5保存的BM25匹配排序，最多取前5 | 否 |
| RRF | 只看两路排名，各贡献1/(60+名次)，相加排序 | 否 |
| Weighted | 每路分数各自做min-max归一化，再按0.5/0.5相加 | 否 |

余弦相似度与BM25的原始分数量纲不同，不能把两列数字直接当作同一种评分。本步使用官方`fusion.py`的两种处理方式，不修改实现；融合输入只有查询与候选排名，标注在融合完成后用于评估，不参与权重选择。

例如某文档在稠密第2、稀疏第1，RRF贡献为1/62+1/61。某路未召回时，该路贡献为0，不凭空补候选。加权融合中单个候选或全相等分数按官方定义归一化为1；最低分可能归一化为0，仍保留在并集中。相同融合分数沿用官方稳定排序，稠密来源先插入，不人工调整相关文档位置。

融合和重排的功能不同：融合汇总已有两路结果；重排更细致地判断候选与查询的关系。重排只能重新排列输入候选，不能找回未进入候选集的文档。候选并集的覆盖率与最终Top-5的Recall分开记录；Precision固定除以5，MRR仅看前5，沿用3-5共同口径。

原稠密结果在这5条查询上已有较高指标，加入词项匹配可能改变甚至降低排序质量，不预设融合一定提高。固定权重不是调优结果，小型英文样例也不代表一般场景。
