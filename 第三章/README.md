## 学习方式

沿用前两章的约定：助手生成代码、讲解并做静态检查，用户亲自运行、反馈输出；助手再核对证据、更新实验记录与周报。每次只推进一个学习目标。预期现象、官方历史结果和本人的实测结果分别记录。
