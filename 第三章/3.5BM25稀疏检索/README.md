## 这一轮看什么

先看model distillation的分词及逐词分数。脚本会打印每个词出现在哪些文档、DF和IDF，以及各文档的TF、长度与BM25贡献，再检查分项之和是否等于引擎总分。

- TF：词在当前文档中出现几次。
- DF：有多少篇文档包含这个词。
- IDF：词的区分度，和DF一起看。
- dl与avgdl：当前文档及整组语料分词后的长度，用于长度校正。

随后比较同一12篇文档、5条查询与标注上的BM25和已保存的MiniLM排序。额外打印一条编码查询XK9-2B4-7Q1，观察编码分词与倒排检索；该条只展示BM25，不计入共同5题均分，也不声称已与稠密检索比较过这个新查询。

## 固定协议及指标口径

采用官方SparseSearchEngine、TextProcessor和BM25，k1=1.5、b=0.75。N、DF、TF和avgdl由本组文本实际分词统计计算。原始RSJ IDF为ln((N−DF+0.5)/(DF+0.5))；官方实现对DF=0返回0，对其余评分IDF设下限1e-6。两种IDF分别保留，避免高频词出现负权重后难以解释。

保留官方英文停用词、大小写和编码处理、小写回退及等分候选顺序；不添加词干化或同义词扩展。无词项匹配时保留空结果，不用零分文档填满前5。

| 指标 | 本次同口径对照 | 官方CLI口径另列 |
| --- | --- | --- |
| Recall@5 | 前5命中标注数/该查询相关文档数 | 相同 |
| Precision@5 | 前5命中数/固定5个位置，不足5也除以5 | 前5命中数/实际返回数；空返回为0 |
| MRR | MRR@5：首个相关结果在前5才计倒数，否则0，再宏平均 | 沿全部匹配候选排名计算RR后平均 |

因此不能把官方BM25的可变返回数Precision，直接与3-4始终返回5条的Precision相比。本步重新从3-4保存的完整排名计算共同口径，原3-4成绩不修改。BM25原始分数和余弦分数也使用不同标尺，只比较排序和统一后的指标。
