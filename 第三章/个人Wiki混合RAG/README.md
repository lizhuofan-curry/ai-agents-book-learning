## 这次先观察什么

判断片段是否真的回答问题，不只看标题和“技术检查true”。例如Agent页中的接口描述可能匹配“脑机接口”的部分字，但不一定能解释脑机接口；EEGNet是脑机接口应用资料，也不能自动替代完整定义。

本步保存relevance_labels=null、metrics=null，不计算或声称Recall、MRR等指标。应先冻结片段、按实际支持程度核对相关性，再比较后续路线；不得拿检索命中本身当金标，或为了提高融合指标反复更换问题、语料或权重。
