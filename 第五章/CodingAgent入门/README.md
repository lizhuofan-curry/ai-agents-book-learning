# Coding Agent入门

这是[十月排期](../../ai-agent-book/01-十月排期.md)要求的官方无编号Starter。先读[第一课](第一课_编码循环与源码入口.md)，再运行[官方Starter离线检查](我的代码/01_官方Starter离线检查.py)。离线检查只列工具和核对入口，不调用模型，不代表已经完成编码任务。

## 按原计划推进

| 步骤 | 本人要做什么 | 完成依据 |
| --- | --- | --- |
| 1. 阅读骨架与离线入口 | 理解用户任务、模型动作、工具执行、反馈和停止；查看真实工具目录 | 本人运行离线入口，能指明消息回传和分发位置 |
| 2. 官方Starter真实编码 | 让模型创建并执行hello_world.py，检查问候函数和真实输出 | 实际模型轨迹、文件内容、执行结果；不能只看“done” |
| 3. 小修改与错误反馈 | 本人改一个需求或条件，观察读改测过程，核对失败或修复 | 本人改动、运行结果和说明 |
| 4. 回到W3交付 | 封装一项本人重复劳动，整理章节笔记 | 一次实际调用及本人总结，不由助手代称独立完成 |

当前仅准备第一步。后续模型选择和执行范围按现有环境核对，真实运行仍由本人启动。不要直接在教材源码目录要求模型改文件；正式任务会另建本次练习工作目录，参考源码保持原样。

## 源码与环境

[官方资料](官方资料/README.md)保存固定版本的主程序、工具实现和许可证。`manifest.json`逐项记录上游Git blob SHA；原始文件不改，教学入口另放“我的代码”。额外示例和官方完整测试套件尚未下载，不冒称已全量复现。

第五章另用项目根目录`.venv-ch5`准备SDK导入环境，原项目`.venv`和`uv.lock`保持原样。离线入口自动选用该环境；不读项目.env，不要求API Key，不初始化模型客户端。真实模型任务稍后单独准备。
